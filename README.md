# ChargeGrid Intelligence
# Problema

Com o crescimento dos veículos elétricos, torna-se importante monitorar o consumo de energia, controlar custos de recarga e fornecer informações claras para os usuários. Além disso, soluções inteligentes ajudam a otimizar o uso da rede elétrica e incentivam práticas mais sustentáveis.

# Solução

O ChargeGrid Intelligence é um protótipo de estação inteligente de recarga desenvolvido com Arduino. O sistema permite registrar sessões de recarga, informar horário de início e término, calcular consumo energético, aplicar tarifas por horário e exibir o valor total da recarga.

Fluxo Simplificado
Usuário -> Teclado 4x4 -> Arduino ->Cálculo de consumo e tarifas-> LCD 16x2

Feedback:
LED RGB + Buzzer

Viabilidade Técnica

A solução utiliza componentes de baixo custo e fácil implementação, como Arduino, LCD, teclado matricial, LED RGB e buzzer. O sistema é funcional, expansível e pode servir como base para aplicações reais de monitoramento energético.

# ChargeGrid Intelligence da GoodWe

O projeto foi desenvolvido considerando conceitos presentes no ChargeGrid Intelligence da GoodWe, especialmente o monitoramento energético, a gestão inteligente de recargas e a busca por maior eficiência operacional. O protótipo funciona como uma demonstração acadêmica simplificada desses princípios.
